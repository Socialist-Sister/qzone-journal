# QQ 空间采集兼容性矩阵

本矩阵用于区分“自动化适配器回归”“真实账号人工验证”和“尚未验证”。记录中不保存 QQ 号、Cookie、动态正文或原始响应。

## 当前自动化覆盖

| 场景 | 适配路径 | 状态 |
| --- | --- | --- |
| 纯文字、长文字、QQ 表情、好友提及 | 说说分类 | 已通过 |
| 单图、多图、原图/缩略图去重 | 说说分类与本人时间线兼容路径 | 已通过 |
| 本人转发、外部视频/网页链接 | 两条路径 | 已通过 |
| 评论回复、官方评论/点赞总数、可见人员详情 | 两条路径 | 已通过 |
| 数值分页、旧恢复点、后续页拒绝、部分完成 | 两条路径 | 已通过 |
| 1 万条动态、5 万个媒体引用的索引与分页读取 | 本地归档 | 已通过 |

## 真实账号观察

| 账号规模 | 已观察结果 | 当前结论 |
| --- | --- | --- |
| 小账号（少量测试说说） | 说说分类可取得本人内容和配图 | 基本可用，仍需重复回归 |
| 大账号（多年内容、含转发） | QQ 曾在后续页拒绝请求；程序可保留部分成果和恢复点 | 兼容性仍受 QQ 风控与接口返回影响 |

## 发布前仍需补齐

- Windows 10 与 Windows 11 各至少进行一次小账号和大账号完整备份。
- 覆盖多年分页、长文本、9 张以上图片、转发视频、会话中断后继续。
- 连续运行三轮，确认无重复爆增、旧档案回退或统计倒退。
- 每次只记录版本、系统、适配器、条数、耗时和结果类别，不记录账号或正文。

采集完成结果中的“适配器状态”分为：正常（说说分类可用）、兼容模式（只读本人时间线）和部分完成（QQ 未继续返回更早内容）。部分完成不等同于完整备份。
